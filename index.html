Frequently Asked Questions

Report কেনেকৈ generate হয়? +
আমাৰ expert astrologers আপোনাৰ birth chart বিশ্লেষণ কৰে আৰু AI-এর সাহায্যে detailed report তৈরি করে। এটা সম্পূর্ণভাবে automated আৰু accurate হয়।
কত সময়ে report পাব? +
সাধারণত payment confirm হওয়াৰ ২-৫ মিনিটৰ ভিতৰে report আপোনাৰ account-ত available থাকে।
Birth time কেন গুরুত্বপূর্ণ? +
Birth time ছাড়া accurate birth chart তৈরি করা যায় না। এটা lagna (ascendant) এবং houses determine করে যা আপোনাৰ ব্যক্তিত্ব আৰু ভবিষ্যৎ বুজতে অত্যন্ত গুরুত্বপূর্ণ।
কি ধরনের payment method ব্যবহার করতে পারি? +
আমরা Razorpay ব্যবহার করি যেখানে Credit Card, Debit Card, UPI, NetBanking সবকিছু accepted হয়।
Report কি format-এ পাব? +
Report HTML format-এ পাবেন যা যেকোনো device-এ দেখতে পারবেন। ভবিষ্যতে PDF download option add করা হবে।
